# 분석 결과 음성 안내 기준

귀 버튼은 결과·이유·예방 행동·확인 방법을 전달한다. 화면 전체를 차례로 읽는 스크린리더 기능이 아니다. 자동 재생하지 않으며 기존 귀 버튼의 원형 모양과 결과별 색을 유지한다.

## 대본 선택

- `speechScript.ts`의 검수 문장만 조합한다. `explanation`, `snippet`, 자유 형식 `risk_factors`, `action_guidance`, 입력 URL·전화번호·개인정보를 음성에 삽입하지 않는다.
- 화면의 위험 요소와 연결되는 실제 evidence의 factor_code를 중복 제거하고 최대 두 개를 선택한다. 우선순위는 전체 해시 일치 링크 → 인증번호/개인정보 요구 → 금전 요구 → 앱 설치 → 명의 주장 → 링크 접속 요구 → 재촉/불이익이다. 수치 위험 점수나 판정 변경에 사용하는 순위는 아니다.
- 코드별 의미를 넘어 업종·기관·사칭 여부를 추측하지 않는다. LINK_CLICK은 접속 요구이지 악성 판정이 아니며, IMPERSONATION은 명의 주장이지 사칭 검증이 아니다.
- URL 위협 목록 일치는 malicious 및 full_hash_verified가 확인된 경우에만 안내한다. 선택된 Google 경고에는 Google 제공임을 읽는다.
- 선택된 이유에 대응하는 예방 행동을 짧게 조합하고 공식 앱/홈페이지 또는 기존에 알고 있던 번호로 확인하도록 안내한다. 다른 요소의 행동이나 UI의 상세 대응 전체를 모두 열거하지 않는다.
- 정상은 안전 보장이 아님을 말하고 금전·개인정보 요청이 있다면 상대방 확인을 권한다. 실제 서버의 정상 반환 정책은 바꾸지 않는다.
- 정보 부족은 판단 불가와 예방 행동을 말한다. 현재 분석 화면은 뒤로 이동 후 수정·재검사가 가능하므로 `canRecheck=true`이다. 재검사 불가 화면에서 재사용할 때는 false로 설정해 공식 연락처 확인 문장으로 대체한다.

## 재생

- 재생 중 같은 버튼은 일시정지, 일시정지 상태에서는 계속 듣기이다. 별도 종료 버튼은 제공하지 않는다. 계속 듣기는 기존 위치에서 재개하고, 재생 완료 후에만 처음부터 다시 듣는다.
- 재생 완료 후 누르면 처음부터 재생한다. 홈·뒤로 이동·새 결과·탭 숨김은 현재 발화와 예약된 문단을 취소한다. 이전 재생의 지연 이벤트는 무시한다.
- 한 문단씩 재생하고 문단 사이에 350ms 쉼을 둔다. 일시정지 중에는 다음 문단으로 넘어가지 않는다.
- 브라우저 기본 속도(rate=1)를 사용한다. 최적 속도나 20~30초 충족을 보장하는 설정이 아니다.
- 미지원·한국어 음성 없음·재생 오류·시작 이벤트 10초 미수신 시 ‘음성 안내를 재생하지 못했어요. 화면의 안내를 확인해 주세요.’를 표시한다. 음성 목록은 누를 때 다시 확인한다.
- 실제 재생 이벤트 이후에만 파동 애니메이션을 표시한다. 일시정지 중에는 없애며 reduced-motion 설정을 따른다.

## 실제 기기에서 남은 확인

자동 테스트는 음성 이벤트를 모의한 것으로 실제 음질이나 이해도 검증이 아니다. iPhone Safari/PWA와 Android Chrome/PWA에서 한국어 음성 준비, 일시정지/계속 듣기 지원, 재생 완료·홈 이동·뒤로 이동, 오류 안내, 겹침 여부를 확인한다.

네 결과별로 선택 음성·기기·브라우저·속도·실제 재생 시간을 기록한다. 20~30초는 초기 목표이며 길면 대본을 먼저 간결하게 조정하고 임의로 속도를 높이지 않는다.

고령자 청취 평가에서는 결과 구분, 의심 이유 이해, 올바른 예방/확인 행동, 정상에 대한 안전 오해, 정보 부족에 대한 정상 오해, 스스로 정지·재개할 수 있는지를 확인한다. 자연스러움만으로 대본을 확정하지 않는다.
