# 가족 공유 UI 통합 미리보기

`feat/family-share-ui`는 `feat/family-share`의 `6b651a4`에서 만들었으며,
`dev_week13`의 `6c6ecd8`까지의 UI·아이콘·TTS를 가져왔습니다.
목적은 API 준비 상태에 관계없이 최신 화면과 전환 흐름을 확인하는 것입니다.

## 실행

이 작업의 체크아웃 경로는 `/workspace/PtoS-family-share-ui`입니다.
그 경로에서 다음 명령으로 실행합니다(Node.js 22.12 이상).

```bash
cd frontend
npm ci
npm run dev
```

`http://localhost:5173/?mode=preview`에서 확인합니다. 백엔드와 API 키는 필요 없습니다.
개발 서버의 기본 모드도 미리보기입니다. 브라우저가 예전에 연결했던 기기 상태와 무관하게 실행됩니다.

- 상단 **개발용 화면 모드**: 최신 UI 미리보기 / 기존 API 연동 화면 전환
- 하단 **개발용 미리보기**: 무료·유료·가족 연결 상태, 보낸 요청·받은 요청 관점 선택
- 하단 **분석 결과 시나리오**: 위험·의심·정상·정보 부족 중 다음 예시 결과 선택
- 모드 전환이나 새로고침 시 모의 상태는 초기화됩니다. 원문·사진·결과를 영속 저장하지 않습니다.

## 확인할 흐름

1. 문자·링크 입력 또는 사진 선택 → 합성 결과 확인 → 가족에게 공유 → 대상 선택 → 공유 창 → **공유할 앱 선택** → 모의 공유 상태
2. 가족 보호 → 가족 추가·초대 → 수락 대기 → 수정하기에서 **모의 수락** → 자동 알림 설정
3. 가족 보호 기록 → 받은 요청 → 보호자 의견 선택·직접 입력 → 의견 보내기 → 완료 팝업 → 기록에 의견 반영
4. 가족 보호 기록 → 보낸 요청 → 가족 의견·대기 상태 확인
5. 공식 확인 가이드 → 분야 → 택배사 → 대응 안내·공식 경로
6. 개발용 미리보기에서 무료 상태 선택 → 프리미엄 안내 → 모의 가입 완료 → 가족 연결

## 모의 동작 범위

| 기능 | 미리보기 동작 |
| --- | --- |
| 문자·링크 분석 | 입력을 분류하지 않고 개발자가 선택한 고정 시나리오를 반환 |
| OCR | 사진은 로컬에서 미리보기만 제공. 서버로 보내지 않고 고정 예시 글자 표시. 확인 체크 후에만 분석 |
| 가입·연락처·초대·자동 알림 | 브라우저 메모리의 예시 상태만 변경. 결제·연락처 접근·전송 없음 |
| 결과 공유 | 실제 결과 링크를 만들지 않음. 앱 선택 버튼은 외부 앱을 열지 않고 모의 공유 상태로 연결. 링크 복사는 비활성 |
| 보호자 의견·기록 | 예시 요청에 의견을 메모리로 반영. 다른 기기 동기화·푸시 알림 없음 |
| 공식 확인 가이드 | 최신 UI의 정적 안내. 우체국 공식 사이트·전화는 사용자 클릭 시 실제 외부 경로로 연결 |
| TTS | 기존 브라우저 음성 합성을 사용. 기기 음성 지원에 따라 다름 |

미리보기의 결과·수신 상태는 실제 분석이나 전송 성공을 의미하지 않습니다.
알림을 받을 수 있다는 화면 문구 역시 UI 시나리오이며 실제 푸시를 등록하지 않습니다.

## 기존 API 연동 화면

상단 모드 선택 또는 `http://localhost:5173/?mode=connected`로 전환합니다.
이때는 `feat/family-share`의 기존 화면과 API를 사용하므로 백엔드가 필요합니다.
가족 기능 설정은 [FAMILY_SHARE.md](FAMILY_SHARE.md), 백엔드 실행은 저장소 README를 따릅니다.
개발 서버를 API 연동 모드로 기본 실행하려면 `VITE_UI_PREVIEW_DEFAULT=connected`를 설정합니다.

최신 UI는 `frontend/src/preview/`에, 기존 연동 화면·API는 원래 경로에 유지했습니다.
백엔드·분석 정책·생성 API 계약은 변경하지 않았으며, Git 전체 병합으로 덮어쓰지 않았습니다.
향후 실제 연동은 이 미리보기의 상태·액션을 `useFamily`와 가족 API에 연결하는 별도 작업입니다.
특히 현재 가족 API가 제공하지 않는 원문 요약·발신자 표시를 실제 데이터처럼 만들어 보내면 안 됩니다.

**현재 `npm run build`는 기존 API 연동 화면을 빌드합니다.**
모의 UI와 개발자 상태 조작은 개발 서버 전용이며 배포 기능에 섞이지 않습니다.

## 검증

`frontend/e2e/ui-preview.spec.ts`는 API 요청을 차단한 상태에서 분석·공유·OCR 확인·보호자 의견 반영과
작은 화면·큰 글씨를 검사합니다. 기존 `family-protect.spec.ts`는 실제 FastAPI의 가족 흐름을 검사합니다.
테스트는 실제 카카오톡·문자 전송, 외부 푸시, 결제 또는 탐지 정확도를 검증하지 않습니다.

2026-11-28 Linux 검증: 프런트 단위 111개, 브라우저 54개 통과(개발 서버 CSP 검사 1개 생략).
배포 빌드의 CSP 검사는 별도 실행해 1개 통과했습니다. 백엔드 1,178개 통과·3개 생략,
실제 한국어 OCR PNG/JPEG는 별도 실행해 2개 통과했습니다. OpenAPI 일치 검사와 프런트 빌드도 통과했습니다.
