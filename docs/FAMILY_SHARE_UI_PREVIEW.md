# 가족 공유 UI 통합

이 브랜치는 feat/family-share의 API에 dev_week13의 화면을 적용합니다.

## 실행과 모드

- 기본 `npm run dev` 및 배포 빌드: 실제 API에 연결한 최신 UI. 백엔드 실행이 필요합니다.
- 개발 서버 `?mode=preview`: API 없는 모의 미리보기. 상단 모드 선택으로도 전환할 수 있습니다.
- `?mode=connected`: 실제 API 화면. 서버 오류를 합성 성공으로 대체하지 않습니다.

## 실제 연동

문자·링크 분석, OCR 후 확인·수정, 결과와 TTS, 시연용 프리미엄 상태 저장,
가족 초대·수락·연결 관리, 자동 알림 동의, 가족 확인 요청 전송,
보낸/받은 요청 기록, 확인 상태 조회, 보호자 의견 전송과 완료 팝업에 실제 API를 사용합니다.
기록의 이름·날짜·위험 요소·의견은 서버 데이터입니다. 의견이 없으면 의견 칸은 비웁니다.
공식 확인 가이드는 정적 안내 화면이며 기관 추가 요청은 명시적인 모의 동작입니다.

## 남아 있는 모의 기능과 차이

순수 미리보기에는 가입·연락처 선택·초대 수락·원문 요약·발신자 정보·공유 상태의 합성 예시가 남아 있습니다.
실제 가족 API는 원문 요약·발신자·원본 링크를 제공하지 않으므로 실제 화면에는 이를 만들어 표시하지 않습니다.
실제 초대 화면은 연락처 대신 이름·관계와 초대 링크를 사용합니다.
프리미엄은 실제 결제 없는 시연용 상태 저장입니다. 웹 푸시는 별도 서버 설정과 기기 동의가 필요합니다.
앱 안의 확인 요청 전송은 서버 연동이며, 외부 앱 공유 창이 닫힌 것을 수신 완료로 간주하지 않습니다.

분석 정책·백엔드·생성 계약은 변경하지 않았습니다. 실제 실행 방법은 README와 FAMILY_SHARE.md를 따릅니다.

외부 앱으로 여는 결과 링크 발급은 아직 미연동입니다. 모의 화면에서만 링크 공유 흐름을 보여주고,
실제 API 화면의 다른 앱 공유는 기존 텍스트 공유·복사 기능을 유지합니다.

검증: 프런트 단위 125개, 백엔드 1,178개 통과(3개 생략), 계약 검사·빌드 통과.
전체 브라우저 검사에서 나온 문제를 수정하고 가족 흐름 및 네 결과/TTS 검사 6개를 다시 통과했습니다.
실제 한국어 OCR 브라우저 흐름과 모의 미리보기 검사도 통과했습니다.
별도 배포 빌드에서 CSP를 적용한 실제 분석·가입 상태 저장·공식 가이드 동작을 확인했습니다.
